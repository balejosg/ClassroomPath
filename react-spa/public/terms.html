Terminos de ClassroomPath

Version vigente: 2026-03-09

ClassroomPath es un servicio para administrar acceso, aulas y politicas de conectividad institucional. Al crear una cuenta aceptas usar el servicio solo con fines autorizados por tu organizacion y conforme a la normativa aplicable.

Uso autorizado

  • No debes intentar obtener acceso no autorizado a otras organizaciones o cuentas.
  • No debes usar ClassroomPath para evadir controles de seguridad o auditoria.
  • Tu organizacion puede gestionar, suspender o revocar tu acceso cuando corresponda.

Datos y seguridad

ClassroomPath procesa datos de cuenta, pertenencia organizativa y actividad operativa necesaria para prestar el servicio, resolver incidencias y mantener trazabilidad.

Transparencia del servicio

ClassroomPath se apoya en OpenPath, el core open source del stack. El servicio se aloja en servidores de la UE y se sirve detras de classroompath.eu.

Responsabilidades

Debes mantener la confidencialidad de tus credenciales, verificar tu correo y notificar a tu organizacion cualquier uso indebido detectado.

Contacto

Si necesitas una copia contractual o una actualizacion de estos terminos, solicita la documentacion a tu administrador de ClassroomPath.
