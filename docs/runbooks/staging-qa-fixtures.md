# Public Note: Staging QA Fixtures

> Status: public stub
> Applies to: ClassroomPath public repository surface
> Source of truth: `docs/runbooks/staging-qa-fixtures.md`

Staging QA fixture procedures are operational material and are maintained privately. They may include
database access paths, lab machine names, VM or snapshot details, staging-only hostnames, and manual
operator steps.

The public repository may include source code for deterministic fixture pages when those pages are
part of the product, but environment-specific QA data loading and lab procedures belong in private
operational documentation.
