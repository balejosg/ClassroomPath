# ClassroomPath Pilot Runbook

> Status: maintained
> Applies to: limited-scope school evaluation
> Last verified: 2026-04-13
> Source of truth: `docs/evaluation/pilot-runbook.md`

Use this runbook to structure a pilot before wider rollout.

## Pilot Goal

The goal of a pilot is not to declare the product "done". The goal is to verify:

- operational fit
- policy change workflow
- blocked-resource diagnosis workflow
- user and admin friction
- evidence needed for a broader decision

## Recommended Pilot Shape

Start small:

- one school or one controlled segment
- one named technical owner
- one named decision owner
- one limited set of endpoints or classrooms
- a defined start and end date

## What To Measure

Track at least:

- how many policy changes were needed
- how many blocked-resource incidents occurred
- how quickly those incidents were resolved
- whether the approval flow was workable
- whether operators could explain the system state to non-technical stakeholders

## Exit Criteria

Do not expand rollout until you can answer:

- which platform and support workflow worked as expected
- what the main operational friction points were
- which local runbooks or ownership gaps must be closed first
- whether the team wants broader rollout, narrower rollout, or no rollout
