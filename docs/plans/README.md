# Plans and Design Notes

> Status: maintained
> Applies to: `docs/plans/*`
> Last verified: 2026-04-13
> Source of truth: `docs/plans/README.md`

This directory contains implementation plans, design notes, and temporary execution documents.

Rules:

- Files in `docs/plans/` are non-authoritative by default.
- Retained plan documents must be English-only.
- Implemented, superseded, or duplicate plans should be deleted instead of kept indefinitely.
- If a historical plan is worth keeping, move it behind the archive boundary rather than treating it as current guidance.
- This directory may legitimately contain only this `README.md` between active planning efforts.

Prefer [`docs/INDEX.md`](../INDEX.md) and the maintained contracts and runbooks for current workflows.
